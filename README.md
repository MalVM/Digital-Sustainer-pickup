# Digital-Sustainer-pickup
An experimental digital guitar sustainer pickup built around custom electromagnetic coils, embedded DSP, and frequency-selective feedback control. The project explores real-time fundamental and harmonic sustain using AGC, oscillation, and phase correction. It has be prototyped using a Electrosmith Seed 2

There are software for the implementation and demo folder. The 2 videos illustrates (most audible), how the strings interact with and without the "Automatic Gain Controller" (envelope).
